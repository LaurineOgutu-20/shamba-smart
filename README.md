# 🌱 Shamba Smart

**A simple agricultural information website built with HTML, CSS, and JavaScript.**

Shamba Smart is a web project designed to help users explore agricultural information, learn about crops, identify common pests and diseases, and understand farming seasons.

## ✨ Features

- 🌾 Crop information and selection
- 🐛 Information about common agricultural pests
- 🌿 Information about crop diseases
- 📅 Farming seasons information
- 📩 Contact page with form validation
- 📱 Responsive website design
- 🖼️ Agricultural images

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## 📂 Project Structure

```text
    ├── beans.jpg

    ├── potatoes.jpg
    └── tomatoes.jpg
```

## 🚀 How to Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website pages.

## 🎯 Project Purpose

This project demonstrates foundational web development skills, including multi-page website structure, styling, JavaScript functionality, and version control with Git.
